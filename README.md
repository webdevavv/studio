# Сайтика

Главная страница веб-студии: 12 последовательных коммерческих блоков. Next.js App Router, React, TypeScript, Tailwind CSS. Серверные компоненты по умолчанию; клиентский JavaScript нужен для меню и переключения макетов. CSS-анимации учитывают prefers-reduced-motion. Превью нарисованы HTML/CSS, без внешних изображений и шрифтов.

## Запуск

Node.js 24, npm 11 (проверено на 24.19.0 / 11.9.0).

```sh
cd /Users/vikulov/Documents/Code/work_files/sitika
nvm use
npm ci
cp .env.example .env.local # только при первой настройке
npm run dev
```

Открыть http://localhost:3000. Сервер слушает только локальный интерфейс. Остановка: `Ctrl+C`. `.env.local` уже подготовлен для локальной работы и исключён из Git. База данных и Docker для запуска не нужны. Интеграция YouGile по умолчанию отключена, её ключи для просмотра сайта не требуются.

Для производственной проверки: `npm run build`, затем `npm run start`. Не запускайте оба сервера на одном порту.

## Проверки

- `npm run build` — сборка и проверка типов.
- `npm run typecheck` — TypeScript.
- `npm test` — браузерные проверки; сервер запускается автоматически при необходимости. Проверяются адаптивность, навигация, клавиатура, FAQ, SSR без JavaScript, robots и 404.
- На macOS Playwright использует установленный Google Chrome. На других системах сначала выполните `npx playwright install chromium`. Другой браузер можно указать через `CHROMIUM_PATH`, адрес уже запущенного сервера — через `TEST_BASE_URL`.

## Структура

- `src/lib/site.ts` — название, контакты, цены, условия и типизированный контент.
- `src/components/ui` — общие элементы.
- `src/components/sections` — интерактивные секции.

- `src/app` — страницы и SEO-маршруты.

## Перед коммерческой публикацией

1. Утвердить название, тексты, цены и условия работы в `site.ts`.
2. Заполнить `contacts.phone` настоящим номером, `contacts.telegram` и `contacts.max` полными HTTPS-ссылками. Пустые контакты скрыты; без них показано демонстрационное состояние.
3. Проверить главную, каталог, блог и необходимые юридические документы перед публикацией.
4. Задать настоящий `NEXT_PUBLIC_SITE_URL` (origin без завершающего `/`). Включать `SITE_INDEXABLE=true` только на утверждённой production-среде. Пересобрать приложение. По умолчанию индексация запрещена, sitemap пуст.
5. Дополнить Open Graph утверждённым изображением и проверить метаданные на настоящем домене.
6. Проверить реальную производительность на выбранном хостинге. Полевые Core Web Vitals не измерялись.

Приём заявок по умолчанию отключён. Сохранена заготовка серверной интеграции YouGile; её подключение — следующий этап. CMS и база данных не добавлялись. Макеты — демонстрационные концепты, не клиентские кейсы.

## Каталог и блог

- `/catalog` — готовые демонстрационные макеты, фиксированная адаптация за 2 000 ₽ и форма выбранного дизайна. Подробнее: [каталог](docs/catalog.md).
- `/blog` — статьи из `content/blog/**/*.md`, поиск, темы и страницы по 12 материалов.
- [Как быстро добавлять статьи пачкой](docs/blog.md) — основная инструкция владельцу сайта.
- `content/blog/_template.md` — образец файла статьи.
- `npm run blog:check` — проверить все материалы; автоматически запускается перед сборкой.
- `npm run test:blog` — проверить чтение Markdown, пакетное добавление, обновления и безопасный HTML.

На обычном Node-сервере файлы `.md` из `content/blog` подхватываются в течение 10 секунд без перезапуска. На хостинге с неизменяемыми сборками новые статьи нужно доставить обычным деплоем. Блог рендерится на сервере и требует Node.js, статический HTML-экспорт не используется.

## Дизайн v2 и taste-skill

По запросу подключён [leonxlnx/taste-skill](https://github.com/leonxlnx/taste-skill), commit `12af471f627f866411b4bd785b19646d3672784c`. Локальная копия: `.agents/skills/taste-skill`, лицензия сохранена рядом. Инструкция для будущих задач — `AGENTS.md`.

Направление: The pinned poster, seed 1471095461. Светлая версия Sky and navy, оранжевый CTA, локально поставляемый Golos Text вместо Epilogue: нужен полный русский алфавит. Кадр сайта удерживает общий формат, содержимое меняется переключателем сфер. Закреплённые подписи продолжают идею в секциях работ и процесса. На мобильном и при reduced-motion подписи идут обычным потоком.

`public/projects/*.png` — авторские растровые превью трёх демонстрационных сайтов с векторными иллюстрациями, а не фотографии или выполненные коммерческие проекты. Внешние фотоколлекции были недоступны. Регенерация: `node scripts/render-concepts.mjs` (нужен установленный Chromium). На публичной странице нет внешних запросов к шрифтам или фотостокам. Лицензия Golos Text поставляется с npm-пакетом `@fontsource-variable/golos-text`.

Команды скилла из корня проекта:

```sh
node .agents/skills/taste-skill/scripts/lint.mjs src
CHROME_PATH=/path/to/chromium node .agents/skills/taste-skill/scripts/inspect.mjs http://127.0.0.1:3000 --out .taste-skill/after
```

В данной изолированной машине Chromium запускается через `/tmp/studio-chrome` с `--no-sandbox`: вложенный sandbox Chromium недоступен. Это локальный запуск браузерной проверки; настройки приложения и TLS не меняются. Скрипт проверки не заменяет ручную оценку дизайна и измерения Core Web Vitals.
