# Главная Сайтики: переработка 31 октября 2026

## Результат

Обновлена существующая главная Next.js, без второго проекта и смены дизайн-системы. Сохранены Golos Text, небесная палитра, оранжевые CTA, мягкие поверхности, композиция устройств с переключением трёх демо, крупные работы, блок о студии и FAQ. Главная остаётся статически отрисованной; блог и каталог сохраняют свои маршруты и серверный рендеринг.

Ровно 12 смысловых секций, в порядке задания: первый экран → зачем бизнесу сайт → выбор формата → портфолио → стоимость → подход → состав услуги → четыре шага → оплата → о студии → FAQ → заявка. Навигация ведёт к услугам, работам, ценам, каталогу и блогу. На телефонах — раскрываемое меню с управлением с клавиатуры и Escape.

## Основные файлы

- `src/app/page.tsx` — структура, содержание, метаданные главной.
- `src/app/home.css` — адаптивные дополнения в существующей дизайн-системе.
- `src/lib/home.ts` — контент FAQ, четыре этапа и типизированные данные портфолио.
- `src/lib/site.ts` — сохранённые цены каталога/хостинга; диапазон индивидуального лендинга 7 000–10 000 ₽ по заданию. Существующее название Сайтика сохранено.
- `src/components/contact-form.tsx` — новая форма.
- `src/lib/brief.ts`, `src/app/api/brief/route.ts` — новый контракт заявки и сохранённый серверный адаптер YouGile.
- `src/components/header.tsx`, `src/app/globals.css` — общая навигация и исправление узкой шапки.
- `src/components/sections/preview.tsx` — сохранённое демо; eager-загрузка и высокий приоритет первой картинки, явная подпись демо.
- `src/components/reveal.tsx`, `src/app/motion.css`, `src/app/soft-surfaces.css` — существующие анимации и поверхности без зависимостей чата.
- `tests/*.spec.ts` — актуальные проверки новых сценариев; `README.md`, `docs/brief.md` — инструкции.
- `.gitignore` — локальные скриншоты QA исключены из Git.

Исходные незакоммиченные изменения окружения, пакетов, AGENTS.md и конфигурации Playwright сохранены. Зависимости для этой работы не добавлялись.

## Чат и форма

Удалены `brief-chat.tsx`, `brief.css`, скрипт проверки старого чата, чатовые состояния, банк пошаговых вопросов, история, имитация диалога, рекомендации и скачивание брифа. Неиспользуемый анимированный заголовок заменён статическим H1 из задания. Старый адрес `/#brief` совместим: ведёт к новой форме, чат не открывает.

Форма содержит только тип сайта, способ связи, обязательный телефон и необязательный комментарий. Сервер получает выбранные значения через прежний `/api/brief`. Сохранены проверка Origin, размера, телефона, серверная фильтрация, экранирование HTML, лимиты, дедупликация и таймаут. Добавлена скрытая ловушка спама. Ошибка возвращается рядом с полем; успех показывается только после подтверждённого ID задачи. На время отправки и после успеха повтор заблокирован; неопределённый результат не вызывает автоматической повторной доставки. Без JavaScript поля отключены, чтобы браузер не отправил персональные данные GET-запросом.

**Интеграция оставлена для следующего этапа.** Реальные ключи и политика не настроены. В текущем режиме UI честно сообщает, что заявка не отправляется. При наличии действующей HTTPS-политики появляется непредустановленный флажок со ссылкой. Фиктивная политика не создавалась. Персональные данные не передаются в аналитику и не сохраняются в localStorage.

## SEO и производительность

На главной один H1; H2 соответствуют секциям, H3 — вложенному содержанию. Добавлены предложенные title и description, Open Graph и canonical от настроенного origin. Настройки индексации остальных страниц сохранены. В изолированной production-сборке с тестовым доменом проверены canonical, Open Graph URL, `index, follow` и `Allow: /`. Локальная среда по-прежнему закрыта от индексации. Перед публичным запуском нужен настоящий production-origin и соответствующий `SITE_INDEXABLE`.

Все изображения локальные, через Next Image с размерами и `sizes`; первый экран загружается сразу, остальные изображения ленивые. Исходные PNG небольшие (около 62–87 КБ); Next Image выполняет оптимизацию при выдаче. Пространство под изображения зарезервировано. Нет iframe и новых тяжёлых библиотек. Основное содержание доступно в SSR без JavaScript. Анимации учитывают reduced-motion.

Полевые Core Web Vitals и Lighthouse не измерялись; гарантированных баллов или показателей LCP/CLS не заявляем.

## Портфолио и оставшийся этап

Все три работы честно обозначены как демонстрационные. Карточки ведут к существующим страницам каталога. Тип `PortfolioProject` содержит стабильный `id`, изображение, категорию, описание, признак демо, текущую ссылку и необязательный `detailHref` для будущей отдельной страницы. Новые страницы с переключением монитора, ноутбука и телефона пока не реализованы.

На следующем этапе: действующая политика, настройки YouGile и согласованная реальная тестовая заявка. Для нескольких экземпляров сервера потребуется общее хранилище дедупликации/лимитов вместо текущих Map; ограничения сохранённой заготовки подробно описаны в `docs/brief.md`. Страница заявки выбранного шаблона в каталоге сохраняет свой прежний неподключённый режим. Публичное развёртывание не выполнялось.
